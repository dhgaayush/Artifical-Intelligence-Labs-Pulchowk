\section{Theoretical Background}

\subsection{Intelligent Agents}

An \textbf{intelligent agent} is a system that perceives its environment through sensors and acts upon it through actuators. The agent function maps percept sequences to actions. Agents are classified based on their internal architecture and decision-making capabilities.

\subsection{Simple Reflex Agent}

A \textbf{Simple Reflex Agent} is the most basic type of intelligent agent. It selects actions based solely on the \textbf{current percept} (sensor input at that moment), using condition-action rules (if-then statements). It has \textbf{no memory} of past states.

\begin{foplbox}
\textbf{Architecture:} $\text{Percept (Current)} \rightarrow \text{Condition-Action Rules} \rightarrow \text{Action}$

\textbf{Key Characteristics:}
\begin{itemize}
  \item Responds only to current environmental stimuli
  \item Uses predefined rule sets (condition $\rightarrow$ action mapping)
  \item Does not maintain any internal state or memory
  \item Works best in fully observable environments
  \item Extremely fast response time
\end{itemize}
\end{foplbox}

\subsection{Model-Based Agent}

A \textbf{Model-Based Agent} maintains an \textbf{internal state} (memory) to keep track of the world's history and unobserved aspects. It uses a \textbf{world model} to make decisions, combining both the current percept and stored knowledge.

\begin{foplbox}
\textbf{Architecture:} $\text{Percept (Current)} + \text{Internal State} \rightarrow \text{Update Model} \rightarrow \text{Condition-Action Rules} \rightarrow \text{Action}$

\textbf{Key Characteristics:}
\begin{itemize}
  \item Maintains an internal representation of the environment
  \item Updates its model based on current percepts
  \item Can handle partially observable environments
  \item Remembers past states and actions
  \item Uses both current percept and internal state for decision making
\end{itemize}
\end{foplbox}

\section{Program 1 --- Simple Reflex Agent}

\subsection{Problem Statement}
Implement a Simple Reflex Agent for the Vacuum Cleaner World that selects actions based only on the current percept (location and room status), with no memory of past states.

\subsection{Rule Table}

\begin{table}[H]
\centering
\caption{Simple Reflex Agent Rule Table}
\begin{tabularx}{\textwidth}{@{}lXl@{}}
\toprule
\textbf{Condition (Percept)} & \textbf{Action} & \textbf{Rule} \\
\midrule
Current room is Dirty & Suck & R1 \\
Current room is Clean AND located in Room A & Move to B & R2 \\
Current room is Clean AND located in Room B & Move to A & R3 \\
Any other case (fallback) & NoOp & R4 \\
\bottomrule
\end{tabularx}
\end{table}

\subsection{Algorithm}
\begin{foplbox}
\begin{enumerate}
  \item Start
  \item Read current percept (location, status) from sensors
  \item IF status equals ``Dirty'' THEN set action = ``Suck''
  \item ELSE IF location equals ``A'' THEN set action = ``Move to B''
  \item ELSE IF location equals ``B'' THEN set action = ``Move to A''
  \item ELSE set action = ``NoOp''
  \item Return/Output the action
  \item End
\end{enumerate}
\end{foplbox}

\subsection{Python Implementation}
\begin{lstlisting}[style=python, caption={Simple Reflex Agent}]
def simple_reflex_agent(location, status):
    # location: 'A' or 'B', status: 'Dirty' or 'Clean'
    if status == "Dirty":
        return "Suck"
    elif location == "A":
        return "Move to B"
    elif location == "B":
        return "Move to A"
    else:
        return "NoOp"

# Percept Sequences to test
percepts = [
    ("A", "Dirty"),
    ("A", "Clean"),
    ("B", "Dirty"),
    ("B", "Clean")
]

print("********** Simple Reflex Agent **********\n")
print("Program by: Aditya Shah")
print("Roll no: 080BCT011\n")

for percept in percepts:
    location, status = percept
    action = simple_reflex_agent(location, status)
    print(f"Percept: Location={location}, Status={status} -> Action: {action}")
\end{lstlisting}

\subsection{Output}
\begin{lstlisting}[style=output, caption={Simple Reflex Agent output}]
********** Simple Reflex Agent **********

Program by: Aditya Shah
Roll no: 080BCT011

Percept: Location=A, Status=Dirty -> Action: Suck
Percept: Location=A, Status=Clean -> Action: Move to B
Percept: Location=B, Status=Dirty -> Action: Suck
Percept: Location=B, Status=Clean -> Action: Move to A
\end{lstlisting}

\subsection{Discussion}
The Simple Reflex Agent correctly responds to all four possible percepts. When a room is dirty, it immediately cleans. When a room is clean, it moves to the other room. The agent has no memory --- it does not track which rooms have been previously cleaned. This means it may revisit already-clean rooms unnecessarily.

\section{Program 2 --- Model-Based Agent}

\subsection{Problem Statement}
Implement a Model-Based Agent for the Vacuum Cleaner World that maintains an internal memory (world model) of room statuses and uses this memory to make decisions.

\subsection{World Model}

\begin{foplbox}
\textbf{Internal State:}
\begin{verbatim}
world_model = {"A": "Clean", "B": "Clean"}
\end{verbatim}

The agent updates \texttt{world\_model[location]} with each new percept, then queries the model to decide which room needs cleaning.
\end{foplbox}

\subsection{Rule Table}

\begin{table}[H]
\centering
\caption{Model-Based Agent Rule Table}
\begin{tabularx}{\textwidth}{@{}lX@{}}
\toprule
\textbf{Condition (World Model)} & \textbf{Action} \\
\midrule
Room A is Dirty & Go to A and Suck \\
Room B is Dirty & Go to B and Suck \\
Both Rooms are Clean & Do Nothing, all are clean \\
\bottomrule
\end{tabularx}
\end{table}

\subsection{Algorithm}
\begin{foplbox}
\begin{enumerate}
  \item Start
  \item Initialize \texttt{world\_model = \{"A": "Clean", "B": "Clean"\}}
  \item Read current percept (location, status)
  \item Update internal memory: \texttt{world\_model[location] = status}
  \item IF \texttt{world\_model["A"]} == ``Dirty'' THEN action = ``Go to A and Suck''
  \item ELSE IF \texttt{world\_model["B"]} == ``Dirty'' THEN action = ``Go to B and Suck''
  \item ELSE action = ``Do Nothing, all are clean''
  \item Return/Output the action
  \item End (internal state persists for next cycle)
\end{enumerate}
\end{foplbox}

\subsection{Python Implementation}
\begin{lstlisting}[style=python, caption={Model-Based Agent}]
# Agent's internal memory (model of the world)
world_model = {"A": "Clean", "B": "Clean"}

def model_based_agent(location, status):
    # Update the agent's memory
    world_model[location] = status

    # Condition-Action Rules using memory
    if world_model["A"] == "Dirty":
        world_model["A"] = "Clean"
        return "Go to A and Suck"
    elif world_model["B"] == "Dirty":
        world_model["B"] = "Clean"
        return "Go to B and Suck"
    else:
        return "Do Nothing, all are clean"

# Test with percept sequences
percepts = [("A", "Dirty"), ("A", "Clean"),
            ("B", "Dirty"), ("B", "Clean")]

print("********** Model-Based Agent **********\n")
print("Program by: Aditya Shah")
print("Roll no: 080BCT011\n")
print("Initial Memory:", world_model, "\n")

for location, status in percepts:
    action = model_based_agent(location, status)
    print(f"Percept: ({location}, {status})")
    print(f"  Action: {action}")
    print(f"  Memory: {world_model}\n")
\end{lstlisting}

\subsection{Output}
\begin{lstlisting}[style=output, caption={Model-Based Agent output}]

\subsection{Discussion}
The Model-Based Agent maintains an internal \texttt{world\_model} dictionary that tracks the status of both rooms. When it perceives a dirty room, it updates the model, cleans the room (sets it to ``Clean''), and returns the appropriate action. When both rooms are clean, it correctly idles with ``Do Nothing''. The key advantage over the Simple Reflex Agent is that it can reason about rooms it is not currently in.

\section{Conclusion}

This lab demonstrated the implementation and comparison of two fundamental agent types in Artificial Intelligence:

\begin{enumerate}
  \item \textbf{Simple Reflex Agent}: Acts solely on the current percept using condition-action rules. It is simple and fast but lacks memory, leading to potentially redundant actions in environments where state tracking is beneficial.

  \item \textbf{Model-Based Agent}: Maintains an internal world model that persists across percept cycles. This memory allows the agent to make more informed decisions by considering both current observations and past knowledge.

  \item \textbf{Comparison}: The Model-Based Agent outperforms the Simple Reflex Agent in scenarios where maintaining state information leads to more efficient behaviour. The key trade-off is between simplicity (Reflex) and intelligence (Model-Based).
\end{enumerate}

The Vacuum Cleaner World problem effectively illustrates how adding internal state to an agent architecture significantly improves its decision-making capabilities, a fundamental principle in AI agent design.
